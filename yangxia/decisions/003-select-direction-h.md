# 决策：003-选定方向 H 向阳印（H-v002 侧向芽苞）

- **日期**: 2026-11-09

## 背景与问题
第二轮四个方向（E 承光印、F 三足鼎印、G 葫芦印、H 向阳印，见 002-reconcept.md）给用户看后，用户说“H还可以，再设计三版对照一下”；据此出 H-v002 侧向芽苞、H-v003 引尖芽苞、H-v004 向阳承光，与 H-v001 并排对照（2026-11-08）。AI 推荐 v003。用户回复“选02”（2026-11-09）。

## 选项与分析
1. **选项 A**: H-v001 原版——三角全圆、右上角小圆尖。简洁，但像对话气泡。
2. **选项 B**: H-v002 侧向芽苞——芽苞转 45°，尖角水平正对“夏”。两印指向关系最直接；风险是像定位针、标签或“播放”箭头，尖角离“夏”近、略挤。
3. **选项 C**: H-v003 引尖芽苞——右上角引出两侧内凹的尖。生长感最强（AI 推荐）；有点像叶子。
4. **选项 D**: H-v004 向阳承光——尖角处亮起一弯光。含义最深；32px 以下像折角。
5. **选项 E**: 第二轮其他方向 E、F、G——用户未选，不再继续。

## 最终结论
按用户选择定为方向 H，选定版本 H-v002 侧向芽苞：尖角水平正对“夏”，“养”向着“夏”生长，两印之间的关系最直接；水滴 + 圆的轮廓简洁，16px 仍可辨。取舍：横躺的水滴容易联想到定位针、标签或播放箭头；尖角距“夏”只有 30，两印略挤；左印横宽 238，作方形图标时需留出横向空间。后续精修可调整尖角长度与两印间距，再试主题色（仍未定）。用户原话：“H还可以，再设计三版对照一下”“选02”。

- 2026-11-09 更正：上文“左印横宽 238”有误，实测为 232.5（高 196）。
