# 养夏 - 品牌视觉规范指南

## 标志结构
- **主标志 `primary`（印边芽苞）**：宣纸色圆角底板上，左为芽苞形白文印——圆身朝右上方生出一枚两侧内凹的芽尖，沿全轮廓刻一圈细线，外留 12 宽的印边，芽尖处细线收成一道细缝，“养”镂空并落在芽苞的视觉重心；右为朱文圆印，“夏”实心，线宽与芽苞的印边同为 12。两字为霞鹜文楷 Medium、同字号同一水平中线；拼音“Yǎng”“Xià”（LxgwPinyin）分别对齐在两字正下方。主标志本身即横版，用于 README 顶部、GitHub 社交预览图等横向场合。寓意：芽苞向着“夏”（太阳）生长，读作“向阳而生、春夏养阳”；细缝如苞片将开，“养”是从里往外长出来的力量。
- **图标**：r1 不提供方形图标；favicon、头像等方形场合暂不使用养夏标志，做成工具时再设计。
- **颜色**：印与文字为新叶绿 #65945A，底板为宣纸色 #FBF3E8。单色版为黑色印、白底；反白版为白色印、黑底。
- **系列关系**：养夏是夏系列的子品牌（背书型），名称含“夏”，不另加“夏 Xià”背书；与夏、印夏、同夏、梦夏、允夏同为“左印项目字、右朱文印夏”的构图。
- **固定地址**：`yangxia/latest/yangxia-primary-latest.svg` 始终指向当前发布。

## 名称写法
中文写“养夏”；需要拉丁字母时写带声调的拼音“Yǎng Xià”（两字分写、首字母大写），无法输入声调的场合（如仓库名、文件名、网址）写“YangXia”或全小写“yangxia”；不写作“Yang Xia”“YANGXIA”，也不与英文意译混用。

## 留白与最小尺寸
- **最小尺寸**：主标志宽度不小于 180px（印刷 45mm）；小于此宽度时拼音不可读、印边细线与芽尖细缝消失，不宜使用。README 中建议显示宽度 320–420px。
- **安全留白**：底板外四周留出不少于圆印直径 1/4 的空白；底板为标志的一部分，不得裁去或改变圆角。
