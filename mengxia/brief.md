# 梦夏 - 需求简报

> 本简报由需求访谈填写（见 logo-workflow 技能第 0 步）；填完并经用户确认后才能开始设计（./logo direction 会检查）。

## 项目类型与架构
- **项目类型**：系列「夏」（xia，背书型）的子品牌（母品牌：xia）
- **系列规则**：`_series/xia/series.md`

## 品牌理念
- **行业/领域**：软件工具；梦夏（MengXia）是本地优先、供应商无关的生成式资产图与生产运行时，面向 AI 短片、广告与视觉内容工作流（Rust，CLI / Core API，开发中；据 GitHub 仓库 XiaTian-X/MengXia 的 About），夏系列的个人品牌工具箱之一
- **目标受众**：主要是品牌所有者本人（制作 AI 短片、广告等视觉内容）；代码开源，访问 GitHub 仓库的开发者与内容创作者是次要受众
- **核心关键词**：梦、生成、影像、资产、本地优先（用户访谈未给出更多关键词）
- **品牌故事/愿景**：“梦”对应生成式内容——把想象变成影像；“夏”表明它属于夏系列（用户未提供更详细的品牌故事）
- **Logo 中的文字**：中文“梦夏”+ 拼音“Mèng Xià”（以 Me4ng Xia4 输入，由拼音字体连字显示声调）；按系列做法，汉字在印内、拼音在印外

## 视觉偏好
- **喜欢的风格**：延续印章意象；梦境、朦胧（云、月、流动的曲线等）；图形单独设计，不照搬夏、印夏、同夏
- **不喜欢的风格（禁忌）**：用户未提出禁忌；参照系列经验，避免亮色大面积铺底加白字的廉价感、避免与其他成员手法重复
- **色彩倾向**：主题色紫棠 / 藤紫（project.toml 暂定 plum #6B4A8E，设计方向确定后再定），须与夏的朱橙、印夏的青金石蓝、同夏的墨色明显区分；计划沿用宣纸色 paper 作底板
- **参考图**：无

## 使用场景
- **生成目标**：svg
- **主要用途**：GitHub 仓库：README 顶部标志、仓库社交预览图
- **计划的封面平台**：github（仓库社交预览图 1280×640）

## 字体策略
> 字体须先登记在 `assets/fonts/fonts.toml`；用 `./logo outline --project <slug>` 转曲时会自动写入 `project.toml` 的 `[fonts] used`。

- **图形**：印章意象结合梦境、朦胧的元素，独立设计；中小尺寸清晰
- **中文**：`lxgw-wenkai-medium`（霞鹜文楷 Medium，与夏、印夏、同夏一致）
- **英文**：拼音用 `lxgw-pinyin-regular`（系列统一），转曲时开启 liga
