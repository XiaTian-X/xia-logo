# 梦夏 - 品牌视觉规范指南

## 标志结构
- **主标志 `primary`（云翼双印）**：宣纸色圆角底板上，左为两瓣云形翅膀的白文印（小瓣在左下靠翼根、大瓣在右上作翼尖，向右上扬起），“梦”镂空；身后紧贴一层浅紫叠印作远翼，前后翼之间留一道宣纸色细缝。右为朱文圆印，“夏”实心。两字为霞鹜文楷 Medium、同字号同一水平中线；拼音“Mèng”“Xià”（LxgwPinyin）分别对齐在两字正下方。主标志本身即横版，用于 README 顶部、GitHub 社交预览图等横向场合。寓意取“庄周梦蝶”：云即是蝶。
- **图标**：r1 不提供方形图标；favicon、头像等方形场合暂不使用梦夏标志。
- **颜色**：印与文字为紫棠 #6B4A8E，叠印为浅紫 #B7A3D3，底板为宣纸色 #FBF3E8。单色版为黑色印、白底；反白版为白色印、黑底（叠印与印同色，靠细缝区分）。
- **系列关系**：梦夏是夏系列的子品牌（背书型），名称含“夏”，不另加“夏 Xià”背书；与夏、印夏、同夏同为“左印项目字、右朱文印夏”的构图。
- **固定地址**：`mengxia/latest/mengxia-primary-latest.svg` 始终指向当前发布。

## 留白与最小尺寸
- **最小尺寸**：主标志宽度不小于 180px（印刷 45mm）；小于此宽度时拼音不可读、前后翼细缝消失，不宜使用。README 中建议显示宽度 320–420px。
- **安全留白**：底板外四周留出不少于圆印直径 1/4 的空白；底板为标志的一部分，不得裁去或改变圆角。

## 错误用法
- 请勿拉伸标志
- 请勿在无足够对比度的背景上使用
- 请勿去掉宣纸色底板，或填掉前翼与叠印之间的细缝
- 请勿去掉浅紫叠印，或改变它与前翼的错开方向与距离
- 请勿改变云翼的形状与扬起角度，或交换两印的位置、阴阳
- 请勿更换字体、让两字不同高，或去掉拼音声调
- 请勿给标志加阴影、描边、渐变或旋转
