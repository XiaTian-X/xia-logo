# 同夏 - 品牌视觉规范指南

## 标志结构
- **主标志 `primary`（契合印）**：宣纸色圆角底板上，左为墨色圆角方印，“同”镂空（阴印）；方印右侧让出一道圆弧咬口，正好容下右边的墨色圆印，“夏”实心（阳印），两者之间缝宽一致。拼音“Tóng”“Xià”分别写在“同”“夏”正下方的印外。中文为霞鹜文楷 Medium，拼音为 LxgwPinyin。主标志本身即横版，用于 README 顶部、GitHub 社交预览图等横向场合。
- **图标**：r1 不提供方形图标；favicon、头像等方形场合暂不使用同夏标志。
- **颜色**：印与文字为墨色 #2E2A28，底板为宣纸色 #FBF3E8。单色版为黑色印、白底；反白版为白色印、黑底。
- **系列关系**：同夏是夏系列的子品牌（背书型），名称含“夏”，不另加“夏 Xià”背书；圆角方印承接印夏，圆印承接母品牌夏。
- **固定地址**：`tongxia/latest/tongxia-primary-latest.svg` 始终指向当前发布。

## 留白与最小尺寸
- **最小尺寸**：主标志宽度不小于 160px（印刷 40mm）；小于此宽度时拼音不可读、契合缝消失，不宜使用。README 中建议显示宽度 320–400px。
- **安全留白**：底板外四周留出不少于方印边长 1/4 的空白；底板为标志的一部分，不得裁去或改变圆角。

## 错误用法
- 请勿拉伸标志
- 请勿在无足够对比度的背景上使用
- 请勿去掉宣纸色底板直接放在深色背景上（墨色几乎不可见，“同”的镂空也会透出背景）；需要无底板时使用反白版
- 请勿改变方印与圆印的相对位置、咬口与缝宽，或交换阴印/阳印
- 请勿把墨色换成其他颜色
- 请勿更换字体、去掉拼音声调，或把“Tóng Xià”写成“Tong Xia”
- 请勿给标志加阴影、描边、渐变或旋转
