# 同夏 - 需求简报

> 本简报由需求访谈填写（见 logo-workflow 技能第 0 步）；填完并经用户确认后才能开始设计（./logo direction 会检查）。

## 项目类型与架构
- **项目类型**：系列「夏」（xia，背书型）的子品牌（母品牌：xia）
- **系列规则**：`_series/xia/series.md`

## 品牌理念
- **行业/领域**：软件工具；同夏（TongXia）让任意两个 AI coding agent 结对开发同一个项目，夏系列的个人品牌工具箱之一
- **目标受众**：主要是品牌所有者本人（用两个 AI coding agent 结对开发）；代码开源，访问 GitHub 仓库的开发者是次要受众
- **核心关键词**：协同、共同、结对、两者合一（用户访谈未给出更多关键词）
- **品牌故事/愿景**：“同”取自协同、共同：两个 AI coding agent 像两个人结对编程一样，在同一个项目里分工协作、互相检查；“夏”表明它属于夏系列（用户未提供更详细的品牌故事）
- **Logo 中的文字**：中文“同夏”+ 拼音“Tóng Xià”（以 To2ng Xia4 输入，由拼音字体连字显示声调）；按系列做法，汉字刻在印内、拼音写在印外

## 视觉偏好
- **喜欢的风格**：延续印章意象；“两者合一”（如两枚印并肩、交叠，或两个半印拼合成一枚完整的印）；东方意蕴；图形单独设计，不照搬夏或印夏
- **不喜欢的风格（禁忌）**：用户未提出禁忌；参照母品牌经验，避免亮色大面积铺底加白字的廉价感
- **色彩倾向**：主题色松绿 / 青绿（project.toml 暂定 pine #2F7A5A，设计方向确定后再定），须与母品牌朱橙、印夏青金石蓝明显区分；可用继承的 vermilion 作点缀、paper 作底色
- **参考图**：无

## 使用场景
- **生成目标**：svg
- **主要用途**：GitHub 仓库：README 顶部标志、仓库社交预览图
- **计划的封面平台**：github（仓库社交预览图 1280×640）

## 字体策略
> 字体须先登记在 `assets/fonts/fonts.toml`；用 `./logo outline --project <slug>` 转曲时会自动写入 `project.toml` 的 `[fonts] used`。

- **图形**：印章意象表达“两者合一”，独立设计；中小尺寸清晰
- **中文**：`lxgw-wenkai-medium`（霞鹜文楷 Medium，与夏、印夏一致）
- **英文**：拼音用 `lxgw-pinyin-regular`（系列统一），转曲时开启 liga
