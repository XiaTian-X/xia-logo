# 允夏 - 需求简报

> 本简报由需求访谈填写（见 logo-workflow 技能第 0 步）；填完并经用户确认后才能开始设计（./logo direction 会检查）。

## 项目类型与架构
- **项目类型**：系列「夏」（xia，背书型）的子品牌（母品牌：xia）
- **系列规则**：`_series/xia/series.md`

## 品牌理念
- **行业/领域**：开源许可；允夏（YunXia）既是一套为夏系列各项目制定的个人开源许可协议文本与说明，也包括配套的许可证生成、选择、检查工具，夏系列的个人品牌工具箱之一
- **目标受众**：主要是品牌所有者本人（为自己的项目选择与维护许可）；协议与工具开源，使用或引用夏系列项目的开发者是次要受众
- **核心关键词**：允许、许可、凭证、契约、开放（用户访谈未给出更多关键词）
- **品牌故事/愿景**：“允”即允许、许可：像盖在契书上的一枚印，写明他人可以怎样使用作品；“夏”表明它属于夏系列（用户未提供更详细的品牌故事；GitHub 上暂无 XiaTian-X/YunXia 仓库）
- **Logo 中的文字**：中文“允夏”+ 拼音“Yǔn Xià”（以 Yu3n Xia4 输入，由拼音字体连字显示声调）；按系列统一构图：左印写“允”、右朱文圆印写“夏”，拼音逐字对齐在下方

## 视觉偏好
- **喜欢的风格**：“允”印取凭证 / 契约（契书、关防、签押之印）与开放的印框（印框留缺口，表示开放、允许进入）的意象；与夏、印夏、同夏、梦夏同一构图
- **不喜欢的风格（禁忌）**：用户未提出禁忌；参照系列经验，避免不规则拼合的软塌形状、避免把多个概念塞进一个形状、两字保持同字号同高
- **色彩倾向**：主题色琥珀 / 金（project.toml 暂定 amber #B5791A，设计方向确定后再定），须与朱橙、青金石蓝、墨、紫棠明显区分；白底对比偏低，按系列做法用宣纸色 paper 底板
- **参考图**：无

## 使用场景
- **生成目标**：svg
- **主要用途**：GitHub 仓库：README 顶部标志、仓库社交预览图
- **计划的封面平台**：github（仓库社交预览图 1280×640）

## 字体策略
> 字体须先登记在 `assets/fonts/fonts.toml`；用 `./logo outline --project <slug>` 转曲时会自动写入 `project.toml` 的 `[fonts] used`。

- **图形**：左为“允”印（凭证 / 开放的印框），右为朱文圆印“夏”；中小尺寸清晰
- **中文**：`lxgw-wenkai-medium`（霞鹜文楷 Medium，与系列一致）
- **英文**：拼音用 `lxgw-pinyin-regular`（系列统一），转曲时开启 liga

## 需求确认
- **确认日期**：2026-10-30
- **用户确认的要点**：在 xia 系列中建子品牌 yunxia（显示名“允夏”，拼音 Yǔn Xià），名称带“夏”不加背书；项目与开源协议许可相关，既有个人许可协议文本也有配套工具（用户选“两者都有”）；定位为个人品牌工具箱；按系列统一构图：左印“允”、右朱文圆印“夏”，霞鹜文楷 Medium 与 LxgwPinyin，拼音逐字对齐；“允”印意象为凭证 / 契约与开放的印框；主题色琥珀 / 金，宣纸色底板；用于 GitHub 仓库（导出 svg，封面平台 github）。系列对比图（夏 r2、梦夏 r1、同夏 r1、印夏 r1）已发给用户。用户回复“确认，开始创建”
