# 决策：001-选定方向 C 关防印

- **日期**: 2026-10-30

## 背景与问题
允夏按系列统一构图（左印“允”、右朱文圆印“夏”）做了 A 开口印、C 关防印、D 印面签押三个方向的初稿，需要选定深化方向。

## 选项与分析
1. **选项 A**: 开口印（A-v001）——方印右边开缺口、正对“夏”，“开放”最直接；但方印外形与印夏、同夏接近，缺口存在感弱。D 印面签押（D-v001）勾形符号感强、东方意蕴弱，也未选。
2. **选项 B**: 关防印（C-v001）——竖长方实心印，细线内框上下留缺口，兼有“凭证/契约”与“开放的印框”；竖长方为系列中唯一的形状。

## 最终结论
选定方向 C，当前选定版本 C-v001。理由：两个意象合在一枚印里，外形与系列其他成员最易区分，构图与系列一致。取舍：32px 以下内框细线与缺口难以分辨；竖长方比圆印高出约 32（两字中线仍一致）。用户原话：“选 C 关防印”（2026-10-30）。
