# 决策：002-定稿 C-v003 关防双印

- **日期**: 2026-10-30

## 背景与问题
允夏选定方向 C 关防印（见 001-select-direction-c.md），经两轮精修：C-v002 降低印高、加粗内框；用户反馈“还是有些不太协调”后，C-v003 改为与圆印等高、外圈与圆印线宽同为 12、内框改为圆角圆头的“[ ]”。用户“选定 v003 并评审”，C-v003 已通过系列评审（_series/xia/series.md，2026-10-30，对比 xia r2、mengxia r1、tongxia r1、yinxia r1）。用户要求“定稿发布 r1”。

## 选项与分析
1. **选项 A**: 以 C-v003 定稿发布 r1，只提供主版 primary（本身即横版），导出 svg，并生成 latest/ 与仓库 README。
2. **选项 B**: 先补方形图标或字标再发布。用途只有 GitHub 仓库（横向场合），暂无方形需求，与系列其他子品牌做法一致。

## 最终结论
选择 A，以 C-v003 定稿发布 r1。理由：竖长关防印承载“凭证/契约”，上下开口的“[ ]”内框承载“开放的印框”，也暗合代码括号，贴合开源许可主题；两印等高、外圈同宽，与系列同一构图、成套；两字同高；系列评审已通过。取舍：没有方形图标；内框与开口在 32px 宽以下难以分辨，16px 只剩竖长方与圆；32px 以下拼音不可读。用户原话：“选 C 关防印”“还是有些不太协调，请让整体更协调”“选定 v003 并评审”“定稿发布 r1”（2026-10-30）。
