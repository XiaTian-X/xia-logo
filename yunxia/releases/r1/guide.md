# 允夏 - 品牌视觉规范指南

## 标志结构
- **主标志 `primary`（关防双印）**：宣纸色圆角底板上，左为竖长关防印（白文），“允”镂空；印面外圈留边内是一对圆角圆头的“[ ]”内框，上下正中各留开口，寓意“开放的印框”，也暗合代码中的括号。右为朱文圆印，“夏”实心。两印等高，关防印外圈留边与圆印线宽相同；两字为霞鹜文楷 Medium、同字号同一水平中线；拼音“Yǔn”“Xià”（LxgwPinyin）分别对齐在两字正下方。主标志本身即横版，用于 README 顶部、GitHub 社交预览图等横向场合。寓意：关防印是官方凭证，象征许可与契约；开口的印框象征开放、开源。
- **图标**：r1 不提供方形图标；favicon、头像等方形场合暂不使用允夏标志。
- **颜色**：印与文字为琥珀金 #B5791A，底板为宣纸色 #FBF3E8。单色版为黑色印、白底；反白版为白色印、黑底。
- **系列关系**：允夏是夏系列的子品牌（背书型），名称含“夏”，不另加“夏 Xià”背书；与夏、印夏、同夏、梦夏同为“左印项目字、右朱文印夏”的构图。
- **固定地址**：`yunxia/latest/yunxia-primary-latest.svg` 始终指向当前发布。

## 留白与最小尺寸
- **最小尺寸**：主标志宽度不小于 180px（印刷 45mm）；小于此宽度时拼音不可读、内框开口难以分辨，不宜使用。README 中建议显示宽度 320–420px。
- **安全留白**：底板外四周留出不少于圆印直径 1/4 的空白；底板为标志的一部分，不得裁去或改变圆角。

## 错误用法
- 请勿拉伸标志
- 请勿在无足够对比度的背景上使用
- 请勿去掉宣纸色底板
- 请勿去掉“[ ]”内框或封上上下开口，或改变开口的位置与宽度
- 请勿改变关防印的竖长比例，或让两印不等高
- 请勿交换两印的位置、阴阳
- 请勿更换字体、让两字不同高，或去掉拼音声调
- 请勿给标志加阴影、描边、渐变或旋转
