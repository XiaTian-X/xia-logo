# 印夏 - 需求简报

> 本简报由需求访谈填写（见 logo-workflow 技能第 0 步）；填完并经用户确认后才能开始设计（./logo direction 会检查）。

## 项目类型与架构
- **项目类型**：系列「夏」（xia，背书型）的子品牌（母品牌：xia）
- **系列规则**：`_series/xia/series.md`

## 品牌理念
- **行业/领域**：软件工具；印夏（YinXia）是 Git 管理的 Logo 设计、版本、发布与交付系统，夏系列的个人品牌工具箱
- **目标受众**：主要是品牌所有者本人（管理夏系列各品牌）；代码开源，访问 GitHub 仓库的开发者是次要受众
- **核心关键词**：印、印记、盖印、落款、规范、追溯（用户访谈未给出更多关键词）
- **品牌故事/愿景**：“印”是盖印、留下印记：每个 Logo 版本、发布都像盖下一枚印，有据可查、不可篡改；“夏”表明它属于夏系列。印夏是夏为自己的品牌打造的工具箱（用户未提供更详细的品牌故事）
- **Logo 中的文字**：中文“印夏”+ 拼音“Yìn Xià”（以 Yi4n Xia4 输入，由拼音字体连字显示声调）

## 视觉偏好
- **喜欢的风格**：延续印章意象、东方意蕴；与母品牌朱文圆印呼应，但图形单独设计
- **不喜欢的风格（禁忌）**：用户未提出禁忌；参照母品牌经验，避免亮色大面积铺底加白字的廉价感
- **色彩倾向**：主题色静蓝 / 青金石蓝（project.toml 暂定 lapis #26619C，设计方向确定后再定），与母品牌朱橙形成冷暖对比、可明显区分；可用继承的 vermilion 作点缀、paper 作底色
- **参考图**：无

## 使用场景
- **生成目标**：svg
- **主要用途**：GitHub 仓库：README 顶部标志、仓库社交预览图
- **计划的封面平台**：github（仓库社交预览图 1280×640）

## 字体策略
> 字体须先登记在 `assets/fonts/fonts.toml`；用 `./logo outline --project <slug>` 转曲时会自动写入 `project.toml` 的 `[fonts] used`。

- **图形**：印章意象，独立设计（不照搬母品牌圆印）；中小尺寸清晰
- **中文**：`lxgw-wenkai-medium`（霞鹜文楷 Medium，系列允许的中文字体之一，与母品牌一致）
- **英文**：拼音用 `lxgw-pinyin-regular`（系列统一），转曲时开启 liga

## 需求确认
- **确认日期**：2026-10-29
