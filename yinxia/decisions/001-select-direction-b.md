# 决策：001-选定方向 B 阴阳对印

- **日期**: 2026-10-29

## 背景与问题
印夏的 A 方印双字（A-v001）与 B 阴阳对印（B-v001）两版初稿已与系列对比图一起给用户看过，需要选定深化方向，并决定是否配方形图标。

## 选项与分析
1. **选项 A**: 方印双字（A-v001）——单枚白文方印，方形，适合图标；但两字偏挤、与“印”的落款意象不如 B 直接。
2. **选项 B**: 阴阳对印（B-v001）——左白文“印”、右朱文“夏”，最贴合名字与落款传统，天然横向，适合 README 与 GitHub 社交预览图；方形场合需另做图标。

## 最终结论
选定方向 B，当前选定版本 B-v001。用户原话：“B不错”。关于方形图标：系统只强制要求主版，项目当前只导出 svg，用途为 README 与 GitHub 社交预览图，均为横向；且发布中有 icon.svg 时封面会默认改用图标。用户决定“先不配图标”，以后需要 favicon、头像等方形目标时再以新发布补 icon.svg（可参考 A 方向的单枚方印）。
