# 印夏 - 品牌视觉规范指南

## 标志结构
- **主标志 `primary`（阴阳对印）**：宣纸色圆角底板上并排两枚青金石蓝方印——左为白文“印”（实心印面、字镂空），右为朱文“夏”（线框、实心字），拼音“Yìn”“Xià”分写于各自印下。中文为霞鹜文楷 Medium，拼音为 LxgwPinyin。主标志本身即横版，用于 README 顶部、GitHub 社交预览图等横向场合。
- **图标**：r1 不提供方形图标；favicon、头像等方形场合暂不使用印夏标志。
- **颜色**：印与文字为青金石蓝 #26619C，底板为宣纸色 #FBF3E8。单色版为黑色印、白底；反白版为白色印、黑底。
- **系列关系**：印夏是夏系列的子品牌（背书型），名称含“夏”，不另加“夏 Xià”背书。

## 留白与最小尺寸
- **最小尺寸**：主标志宽度不小于 160px（印刷 40mm）；小于此宽度时拼音不可读，不宜使用。README 中建议显示宽度 320–400px。
- **安全留白**：底板外四周留出不少于一枚方印边长 1/4 的空白；底板为标志的一部分，不得裁去或改变圆角。

## 错误用法
- 请勿拉伸标志
- 请勿在无足够对比度的背景上使用
- 请勿去掉宣纸色底板直接放在深色背景上（白文“印”会透出深色背景）；需要无底板时使用反白版
- 请勿交换两枚印的位置或互换白文/朱文
- 请勿把青金石蓝换成母品牌的朱橙或其他颜色
- 请勿更换字体、去掉拼音声调，或把“Yìn Xià”写成“Yin Xia”
- 请勿给标志加阴影、描边、渐变或旋转
