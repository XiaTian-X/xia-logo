# 夏 - 品牌视觉规范指南

## 标志结构
- **主标志 `primary`**：只含“夏”（霞鹜文楷 Medium）的朱文圆印，印下居中为拼音“Xià”（LxgwPinyin，带去声），竖版。用于 README、封面、介绍页等中大尺寸场合。
- **横版 `horizontal`**：同一枚圆印，右侧为“Xià”，与圆心水平对齐。用于 README 顶部、横幅、页眉等横向空间。
- **图标 `icon`**：只有圆印、不带拼音，用于小尺寸与图标类场合。
- **头像 `avatar`**：宣纸色满版底，内缩朱橙圆环与“夏”；上传到 GitHub、社交平台后由平台裁成圆形。
- **字标 `wordmark-cn` / `wordmark-pinyin`**：不带印框的“夏”与“Xià”，用于只需文字的场合，不与印章版同时重复出现。
- **规则**：印面只刻汉字，拼音一律写在印外（与子品牌印夏一致）。
- **颜色**：标志色朱橙 #D9531E；头像底色宣纸色 #FBF3E8。单色印刷用黑色版，深色背景可用反白版。
- **固定地址**：`xia/latest/xia-<版式>[-<配色>]-latest.svg` 始终指向当前发布。

## 留白与最小尺寸
- **最小尺寸**：主标志宽度不小于 64px（印刷 15mm）；横版高度不小于 40px（印刷 10mm）；小于上述尺寸改用 icon；icon 不小于 24px（印刷 6mm）；头像上传尺寸不小于 400×400px。
- **安全留白**：圆印与拼音组合四周留出不少于圆印直径 1/8 的空白；字标四周留出不少于字高 1/4 的空白。留白内不放其他文字或图形。

## 错误用法
- 请勿拉伸标志
- 请勿在无足够对比度的背景上使用
- 请勿把拼音放回印内，或在印面加刻其他文字
- 请勿把朱文印改成实心色块或白字橙底（白文），也不要给印面加填充色
- 请勿更换“夏”与“Xià”的字体，或调整两者的大小比例与相对位置
- 请勿去掉拼音的声调符号，或把“Xià”写成“Xia”
- 请勿给标志加阴影、描边、渐变或旋转
- 请勿在照片等复杂背景上直接使用朱文印；需要时先放宣纸色或白色底板
