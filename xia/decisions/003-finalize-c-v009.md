# 决策：003-改版定稿 C-v009 拼音移至印外

- **日期**: 2026-10-29

## 背景与问题
r1 主版（C-v008）把拼音“Xià”刻在圆印内。子品牌印夏 r1 采用“印章只刻汉字、拼音写在印外”的排法后，用户提出“夏 logo好像也应该把拼音放到外面”，需要决定是否改版并发布 r2。

## 选项与分析
1. **选项 A**: 保持 r1——圆形主版紧凑，但与印夏排法不一致，印内“夏”较小（字号 250），48px 时拼音已不可辨。
2. **选项 B**: 拼音移至印外（C-v009）——主版为只含“夏”的圆印加印下 Xià（竖版 512×644），横版为圆印加右侧 Xià；图标、字标、头像沿用 r1。

## 最终结论
选择 B，以 C-v009 发布 r2。理由：与印夏一致，系列统一；印面只刻汉字更符合印章传统；主版、横版、图标、头像共用同一枚印，小尺寸更清楚。取舍：主版由圆形变为竖版，横版去掉长方印框；拼音单独在印外略显轻。母品牌改版后需逐项向用户确认印夏是否跟进。用户原话：“先出草案对比”“按草案发布 r2”（2026-10-29）。
