# 决策：002-定稿 C-v008 朱文圆印

- **日期**: 2026-10-29

## 背景与问题
方向 C 已选定 C-v008（见 001-select-direction-c.md），用户要求“定稿发布 r1”，需要确认 C-v008 可作为母品牌“夏”首个发布的主标志，并确定配套版式。

## 选项与分析
1. **选项 A**: 以 C-v008 定稿，主版用 C-v008，另配 icon（只含“夏”的朱文圆印）、horizontal（朱文长方印，夏 + Xià 横排）、wordmark-cn、wordmark-pinyin 与手工头像 avatar（宣纸色满版底 + 内缩圆环 + 夏）。
2. **选项 B**: 继续迭代（如加粗圆环、为拼音寻找更粗字重）后再发布。拼音字体只有 Regular 一个字重，短期内无法解决，且用户已确认现有效果。

## 最终结论
选择 A，以 C-v008 定稿发布 r1。理由：64px 以上主标志清晰，彩色/单色/反白完整，白底与深色底均可用；小尺寸问题通过只含“夏”的 icon 与手工头像解决。取舍：32px 以下主版拼音不可读、圆环偏细，指南中规定主版最小尺寸，小于该尺寸改用 icon。用户原话：“定稿发布 r1”（2026-10-29）；各版式草案（朱文风格）用户已看过并说“按朱文印转正”。
